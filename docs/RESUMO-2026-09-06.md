### 3. Correção de segurança + limpeza
- Dois arquivos entraram sem querer num commit anterior via `git add -A`:
  - `apps/google-services.json` (config do Firebase, com uma **API key do
    Firebase**) — **movido** pro lugar certo (`apps/motoboy-app/`, que é
    gitignored) e **removido do histórico versionado**. De quebra, isso
    completou a fiação do Firebase — o próximo build do APK já pega o push.
  - `app.json` na raiz (com um `easProjectId` diferente, `71fa495d-…`) —
    removido. O projeto Expo que funciona é o `5c851aad-…` no
    `app.config.js`. Se você vir um segundo projeto Expo em expo.dev que não
    reconhece, pode ignorar/apagar.
  - `.gitignore` reforçado pros dois não voltarem.
  - **A API key do Firebase ficou brevemente numa branch pública no GitHub.**
    Severidade baixa (essa chave é um identificador que já vai embutido no APK
    de qualquer forma, protegida por package name + SHA-1), mas o ideal é você
    **restringir a chave** no Google Cloud Console → APIs & Services →
    Credentials → a API key → "Application restrictions" = Android apps, e
    "API restrictions" = só as APIs do Firebase que usa. Leva 2 min e fecha
    qualquer risco.

### 4. Rotas reais — provedor Mapbox implementado
- Antes: distância/tempo sempre em **linha reta ×1,3**. Agora, se você
  adicionar um `MAPBOX_TOKEN`, rota + ETA ficam reais **e** os tiles do mapa
  ficam mais bonitos — um token só, dois ganhos. Free tier 100k/mês.
- Fallback automático pra linha reta se o Mapbox falhar.
- Passo a passo: `docs/ROTAS-SETUP.md`.

### 5. Backup semanal automatizado

  guarda o arquivo no GitHub por 90 dias.
- Fica "pulado" (verde) até você adicionar o secret `SUPABASE_DB_URL`
  (2 min — `docs/BACKUP.md`).
- Cobre o buraco do plano grátis da Supabase (7 dias, sem self-restore).
